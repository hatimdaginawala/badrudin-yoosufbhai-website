BADRUDIN YOOSUFBHAI & COMPANY — MULTI-PAGE WEBSITE
=================================================

Open index.html to start at the homepage.

Separate pages:
- index.html — Homepage
- about.html — Company history and overview
- products.html — Main product categories
- everest.html — Everest boards and fibre cement products
- decorative-panels.html — Cascade, Alpine, Electra, Ripple, Diamond, Swirl, Oceanic, Lake & Hill, Miral, Sandslate, Fluted Panels and woodgrain reference gallery
- switches.html — Switch plates and modular accessory reference gallery
- roofing.html — Everest Evercool cement roofing sheets
- brochures.html — Company and manufacturer PDF library
- contact.html — Phone, WhatsApp, address, GSTIN and directions

All CSS and JavaScript are local. Google Fonts load from the internet; system fallbacks are included.
The site is static HTML/CSS/JS. No Node.js, database or build process is required.
Upload the complete folder contents, preserving assets/ and brochures/, to your hosting public_html directory.

The decorative panel and switch galleries use the client's supplied product reference photographs.
A generated architectural image is used as the new homepage and page-banner visual.
Confirm product details, current availability and specifications before publication.
